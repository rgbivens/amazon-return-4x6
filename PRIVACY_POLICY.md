# Privacy Policy — 4x6 Return Label Printer for Amazon

**Last updated:** September 15, 2026

This extension does not collect, store, sell, or transmit any personal
information or browsing data.

## What the extension does

When you click its button on an Amazon return-instructions page, the
extension reads the shipping label image, the return authorization slip
image, and the item description table that Amazon already displays on
that page, and rebuilds them as two print-ready pages in a new browser
tab. This all happens locally, inside your own browser.

## What the extension does not do

- It does not send any data to a server operated by the developer or
  anyone else — there is no server.
- It does not use analytics, tracking pixels, or third-party scripts.
- It does not read or modify any website other than Amazon
  return-instructions pages.
- It does not store any data after the browser tab is closed.

## Permissions

The extension requests no special browser permissions. It only runs a
content script on amazon.com pages to detect the return label and slip
already visible on the page.

## Changes to this policy

If this policy changes, the "Last updated" date above will be revised.
